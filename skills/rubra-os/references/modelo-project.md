# Modelo de Project por cliente (claude.ai)

Um Project por cliente. Configuração única, depois é só conversar dentro dele.

## Nome do Project

`RUBRA · <Nome do cliente>`

## Instruções do Project (colar e trocar o que está entre <>)

```
Cliente da RUBRA: <Nome do cliente>.
Use a skill rubra-os em todo pedido.
Contexto do cliente: arquivos deste Project (contexto.md, design.json, decisoes.md) e a pasta do Google
Drive "RUBRA AGENCY OS / CLIENTES / <Nome do cliente>".
Antes de criar, leia decisoes.md. Ao final de cada aprovação ou rejeição, me entregue o registro para decisoes.md.
Nunca use cores, fontes, referências ou soluções de outro cliente.
```

## Arquivos do Project (Conhecimento)

Suba: `contexto.md`, `design.json`, `decisoes.md`, o manual de marca (PDF) e até 10 referências-chave.
Atualize `decisoes.md` no Project quando acumular registros novos (ou mantenha só no Drive e peça para o
Claude ler de lá).
