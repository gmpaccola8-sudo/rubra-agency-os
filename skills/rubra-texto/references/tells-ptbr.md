# Sinais de texto escrito por IA (PT-BR) — e o que fazer no lugar

Adaptado do guia copy-tells do Taste Skill (MIT, nov/2026) para português e para publicidade.
Um sinal isolado prova pouco; repetição e acúmulo são o problema. Toda proibição vem com o
movimento positivo: sem ele, o modelo troca pelo sinônimo mais próximo.

| Sinal | Faça no lugar |
|---|---|
| Verbos de promessa vazia: descubra, conheça, eleve, transforme, desbloqueie, potencialize, revolucione | O verbo da ação real (encomende, agende, leia, prove) ou o fato |
| Adjetivos de catálogo: incrível, único, exclusivo, inovador, completo, premium, de excelência, diferenciado | Um fato verificável que prove a qualidade, ou nada |
| Frases de abertura prontas: "No mundo de hoje…", "Você já parou para pensar…", "Imagine…" | Comece pelo fato ou pela cena |
| "Mais do que X, é Y" / "Não é só X, é Y" | Diga Y diretamente |
| Pergunta retórica respondida na sequência ("O segredo? O tempo.") | Afirmação direta |
| Dois-pontos de revelação ("Uma coisa mudou: tudo.") | Frase inteira, sem suspense fabricado |
| Gerúndio pendurado (", garantindo uma experiência…", ", proporcionando…") | Corte o rabo; se importa, vire frase própria com fato |
| Tríade de adjetivos ("leve, crocante e saboroso") | Um, verificável |
| "Feito com amor", "carinho em cada detalhe", "paixão pelo que faz" | O gesto concreto que mostra o cuidado |
| Metáforas gastas: jornada, universo, ecossistema, "no coração de", "onde X encontra Y" | O nome da coisa, da rua, do processo |
| Travessão em toda frase | Ponto final |
| Exclamação em texto corrido; emoji como marcador de lista | Sem; a força vem do conteúdo |
| CTA genérico: "Saiba mais", "Clique aqui", "Não perca!" | O que acontece ao agir, e quando |
| Resíduo: "[Nome da empresa]", "Claro!", markdown na peça (`**`, `##`) | Revisar a peça renderizada antes de entregar |
